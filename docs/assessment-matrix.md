# Матрица исследования (28.10.2026)

| Источник | Статус проверки | Что используем |
|---|---|---|
| [ФИРПО](https://de.firpo.ru/) | Публичный портал; полный комплект в локальном релизе не зафиксирован | Ориентиры на требования к проектированию, БД, тестированию и документации |

| [Открытые материалы](https://om.firpo.ru/) | Доступность отдельных комплектов меняется | Проверять код/год/квалификацию перед каждой экзаменационной тренировкой |
