# DevForge

Локальная интерактивная академия программирования. Первый релиз включает рабочее ядро этапа 1: тёмный интерфейс, 9 связанных треков, практический Python-модуль из 24 разнообразных заданий, SQL-тренажёр на реальной SQLite-структуре, изолированный браузерный запуск, проверку результата, подсказки, автосохранение черновиков и SQLite-историю попыток.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. `npm run dev` запускает Vite и API (порт 3001). Для production-проверки: `npm run build`, затем `npm start`.

Экспорт прогресса доступен через `GET /api/export`. База хранится в `data/devforge.sqlite` и создаётся автоматически.

## Безопасность первого релиза

Python запускается в Web Worker через Pyodide, сеть и XMLHttpRequest отключены, вывод ограничен. SQL выполняется в отдельной in-memory sql.js базе с демонстрационной таблицей. C++, PowerShell и Git пока представлены архитектурными треками без опасной симуляции исполнения.

## Матрица подготовки к экзамену

В `docs/assessment-matrix.md` зафиксированы проверенные источники и статус доступности. Упражнения DevForge оригинальные и не выдаются за официальные варианты.

## Web Lab (этап 2)

В меню появился раздел **Web Lab**. Он содержит изолированный `sandbox` iframe без `allow-same-origin`, Monaco Editor с вкладками HTML/CSS/JavaScript, предпросмотр, консоль, ошибки, сохранение черновика и объективную проверку шести стартовых заданий. Код страницы не получает доступ к приложению; сообщения принимаются только с маркером `devforge-web-lab`, внешний JavaScript автоматически не подключается. Встроен тайм-аут наблюдения выполнения и ограниченная проверка критериев.

## Браузерный smoke-тест

При установленном Chromium запустите API и Vite, затем выполните `npm run browser:test` (или задайте `DEVFORGE_URL`). Скрипт открывает главную страницу, Web Lab, Monaco Editor, запускает и проверяет задание и меняет viewport на мобильный. В текущем окружении Playwright доступен, но исполняемый Chromium отсутствует; команда завершается ошибкой запуска браузера до выполнения сценариев.

## Web Lab 2.2: расширенный каталог

Каталог содержит 44 HTML-задания, 53 CSS-задания и 117 JavaScript-заданий. Для аудита доступны `webTopicMatrix` и пять проектных спецификаций `webProjects`: персональная страница, адаптивный многостраничный сайт, менеджер задач, приложение с API и итоговое веб-приложение. Каждый проект содержит brief, критерии приёмки и набор проверок.
