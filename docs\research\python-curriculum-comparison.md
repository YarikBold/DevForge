# Сравнение программ

| Область | Stepik 58852 | DevForge после аудита | Решение |
|---|---|---|---|
| Начало | Ввод-вывод и структурное программирование | 25-темный junior-путь | Публиковать отдельный Basics-путь перед API и ООП |
| Практика | Автоматическая проверка и несколько типов упражнений | JSON-каталог, часть типов пока требует отдельного интерфейса | Реализовать code runner, quiz, match и debug отдельно |
| Теория | Текстовые конспекты перед практикой | Теория и термины хранятся в курсе | Расширить построчный разбор и эксперименты |
| Контроль | Задачи с ростом сложности и мини-проект | Контрольные описаны в JSON | Превратить контрольные в исполняемые наборы |

Выводы, зависящие от Stepik, основаны на открытой странице курса; предложения по DevForge являются собственной архитектурной рекомендацией.
